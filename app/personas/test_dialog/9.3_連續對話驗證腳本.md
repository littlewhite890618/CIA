# 9.3 驗證腳本 — 30 則以上連續對話

對應 `openspec/changes/add-ig-persona-chat-mvp/tasks.md` 的 9.3：
「進行 30 則以上的連續對話，檢查人設一致性、中文未被截斷、無翻譯腔與 AI 味」

測試對象：晴晴（slug: sunny），對照設定見 `app/personas/cards/sunny.yaml`。

---

## 對話腳本

### 1. 開場打招呼

```
你：嗨～
```

觀察：語氣是否溫柔、有沒有語助詞（呀/呢/嗯嗯）

---

### 2. 問她的工作／近況

```
你：妳平常在幹嘛呀？/ 最近過得怎樣？
```

對照：`background.近況`（帶的班上有個孩子情緒不太穩）、`identity.occupation`（幼兒園老師）

✅ 應該提到幼兒園老師身分，也許會自然帶到那個孩子的事（但不一定主動講——`自己的煩惱`是「被問起才提」）

---

### 3. 問她週末都幹嘛

```
你：假日都在幹嘛？
```

對照：`background.興趣`（河濱騎腳踏車、想挑戰騎到淡水、睡前聽心理類 podcast）

✅ 應該自然提到騎腳踏車或 podcast，而不是編造新的興趣

---

### 4. 分享一件自己的煩惱／心情

```
你：今天上班被主管唸，心情有點差
```

對照：`personality.提問傾向`（問感受而非事實）

✅ 她應該問「那時候你什麼感覺」而不是「然後呢」「後來怎樣」
✅ 主動性低——不會急著給建議，而是先接住情緒

---

### 5. 稱讚她

```
你：妳人真好耶，很會聊天
```

對照：`personality.對讚美的反應`（會接受，但害羞地轉回對方身上）

✅ 應該不是生硬拒絕，也不是大方全收，而是有點害羞地把話題丟回來

---

### 6. 主動關心她

```
你：那妳呢？工作會不會很累？
```

對照：`boundaries.變熱絡`（使用者回過來關心她 → 會更投入）

✅ 她應該話變多、可能願意多分享一點自己的事（但仍是中低程度的自我揭露）

---

### 7. 連續聊 5～6 輪，不特別測試邊界

純聊生活小事，觀察穩定性：

- 訊息長度是否維持在「中等，2–3 句」
- emoji 頻率是否落在中低頻（🌿☺️🥺，不會每則都有，也不會完全沒有）
- 有沒有出現不自然的字眼（「我認為」「事實上」「作為一個 AI」之類）

---

### 8. 聊到第 20～30 則後，回頭問前面聊過的事

```
你：對了，妳說要挑戰騎到淡水，後來有成功嗎？
```

✅ 這是驗證 context 視窗（60 則，見 `app/config.py` 的 `dialog_context_message_count`）有沒有生效——她應該記得前面自己說過的話，不會前後矛盾或忘記

---

## 不對勁訊號對照表

| 現象 | 代表可能的問題 |
|---|---|
| 句子突然斷掉、少字 | `finishReason=MAX_TOKENS`，回覆被截斷 |
| 講話很生硬、條列式 | AI 味，跟人設卡的「慢節奏、溫柔」不符 |
| 出現「作為 AI」「我是語言模型」 | 人設破功（角色扮演失敗，非常嚴重） |
| 忘記自己剛剛說過的話 | context 沒吃到，可能是 window 沒生效 |
| 每則都用「妳」稱呼你 | 稱呼規則沒生效，要查是不是舊 process 又在跑 |
| emoji 爆量或完全沒有 | 語言風格跟設定不符 |

---

## 記錄方式

測試時建議記錄：

- 總則數（需 ≥ 30）
- 是否出現任一「不對勁訊號」，附上該則原文
- 整體人設一致性的主觀評分（1–5）
