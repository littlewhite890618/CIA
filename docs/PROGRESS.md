## 5. 不會因 Claude Code 而加速

- Meta 審核等待：完全外部
- 人設調校、報告品質判斷：需人的語感判斷，且須實際在 IG 上對話
- 每個角色的 IG 帳號建置：人工操作 Meta 後台，約半小時／角色，無 API 可自動化
- 單一角色帳號的對話承載量：原估「每小時 7–10 場」已作廢（見 4.1）。2026-10-19 重算，**目前的瓶頸是 Gemini 免費額度，不是 IG**：回話模型（gemini-3.5-flash-lite）每天 500 次、每分鐘 15 次，以每段對話晴晴平均回 10 則計，**一天約 45～50 段對話**就會用完，超過的使用者只會收到備用語句。**對外推廣前須改用付費方案**。IG 發訊上限 `SEND_RATE_LIMIT_PER_HOUR` 維持 200，上線後以發訊監測（`scripts/send_health.py`）觀察，見 add-persona-authoring-console design.md 決策 11
