## Why

真機使用一段時間後，使用者回報四個問題：晴晴偶爾冒出簡體字；「今天聊得怎麼樣？」的按鈕在 Instagram 網頁版顯示不出來，看不到教練回饋；回饋在對話靜默 25 分鐘後就跳出來，時機太近；取得設定連結的關鍵字「設定」太容易在聊天中誤觸。這四項都直接影響使用者體驗，且彼此獨立、改動範圍小，合為一個變更處理。

## What Changes

- **繁體中文輸出**：晴晴的回覆、教練報告、長對話摘要一律使用繁體中文（台灣用語）。提示中明寫，送出前再以程式把殘留的簡體字轉成繁體當保險。使用者自己傳的訊息不做任何轉換
- **BREAKING 教練回饋改成網頁連結**：取消「看這次的回饋」按鈕，改傳一則帶連結的文字訊息，連結開啟新的回饋網頁。報告不再以私訊文字送出
- **報告仍在使用者打開連結時才產生**：沿用「使用者表示要看才產生」的原則，第一次打開時產生並保存，之後再打開直接讀取
- **BREAKING 送出時機改為凌晨四點**：對話結束（靜默 25 分鐘的判定不變）後，等到下一個凌晨 04:00（台灣時間）才送出。同一位使用者在這段期間結束的多段對話合併成**一則訊息、一個連結**，網頁列出每段對話的回饋。仍遵守 24 小時訊息視窗與最少互動門檻
- **回饋連結的保護**：連結 7 天內有效，只能在第一個打開它的瀏覽器上使用（沿用設定連結的機制），只看得到這位使用者自己的回饋
- **已送出的舊按鈕**：使用者點擊先前送出的「看這次的回饋」按鈕時，改回覆一則該場對話的回饋連結
- **BREAKING 設定連結的關鍵字改為「芝麻開門」**：「設定」改當一般聊天訊息；設定頁上的錯誤提示一併改用新關鍵字
- **BREAKING 開場改為一行問候**：每段新對話開頭只顯示「嗨，我是晴晴，戀愛顧問🌿」。拿掉原本的「AI」「不是真人唷」，也拿掉「想調整我的個性，隨時傳『設定』給我就好」的提示（使用者決定，風險見 design.md 決策 10）

## Capabilities

### New Capabilities

（無）

### Modified Capabilities

- `coach-report`：邀請的時機與形式（凌晨四點、合併、文字連結）、同意的定義（打開連結即表示要看）、報告的呈現（網頁而非私訊）、連結的存取限制、報告使用繁體中文
- `persona-chat`：角色回覆使用繁體中文；AI 身分揭露改為不含「AI」的開場問候
- `tenant-access`：取得設定連結的關鍵字由「設定」改為「芝麻開門」

## Impact

- **程式**：`app/main.py`（移除對話結束時發邀請、新增每日 04:00 排程、舊按鈕改回連結、關鍵字）、`app/dialog/coach_report.py`、`app/dialog/summary.py`、`app/personas/prompt.py`、`app/web/`（新增回饋頁 API）、`app/auth/`（回饋連結的簽章與單一瀏覽器限制，沿用設定連結的做法）、`app/config.py`
- **前端**：新增回饋頁（與設定頁同一套 React 專案與視覺風格）；設定頁的錯誤提示文字改用新關鍵字
- **資料庫**：新增「每日回饋」紀錄（哪位使用者、哪些對話、何時送出），場次記錄被併入哪一份每日回饋；需要 Alembic 遷移
- **套件**：新增簡繁轉換套件（OpenCC 的 Python 版）
- **設定**：`SETTINGS_KEYWORD` 預設改為「芝麻開門」；新增回饋連結有效天數、送出時刻等可調設定
- **不受影響**：靜默 25 分鐘判定對話結束、話題萃取、訊號偵測、長對話摘要的觸發時機都不變
