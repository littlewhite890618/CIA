# realtime-signals Specification

## Purpose

在對話進行的當下辨識並記錄使用者的溝通行為訊號，作為後續教練回饋的唯一資料來源，確保教學所需的證據在 session 結束時即逐則標記並關聯至原句，而非等到報告生成時才從純文字重新推斷。

## Requirements

### Requirement: 行為訊號偵測

系統 SHALL 於 session 結束後，針對該 session 的每一則使用者訊息偵測其溝通行為訊號，並 MUST 支援地雷、句點與亮點三類訊號。偵測結果 MUST 關聯至產生它的具體訊息。

#### Scenario: 偵測到地雷行為

- **WHEN** 使用者訊息命中角色人設卡中定義的地雷行為
- **THEN** 系統記錄一筆地雷類訊號，包含其嚴重程度與命中的具體原因，並關聯至該則訊息

#### Scenario: 偵測到句點行為

- **WHEN** 使用者的回覆屬於敷衍回應、連續封閉式提問，或完全未回應角色拋出的話題
- **THEN** 系統記錄一筆句點類訊號並關聯至該則訊息

#### Scenario: 偵測到亮點行為

- **WHEN** 使用者提出開放式問題、成功接住角色拋出的話題、進行適當的自我揭露，或回應了角色的情緒
- **THEN** 系統記錄一筆亮點類訊號並關聯至該則訊息

#### Scenario: 無明顯訊號的訊息

- **WHEN** 使用者訊息不屬於上述任何一類
- **THEN** 系統不記錄訊號，該則訊息仍正常保存

#### Scenario: 單則訊息命中多類訊號

- **WHEN** 一則訊息同時具備亮點與地雷特徵
- **THEN** 系統分別記錄多筆訊號，不因擇一而遺漏

### Requirement: 訊號偵測不阻塞對話

訊號偵測 MUST 在 session 結束後以背景任務執行，MUST NOT 在對話進行中佔用回覆流程。偵測失敗 MUST NOT 影響使用者。

#### Scenario: 對話進行中不偵測

- **WHEN** 系統收到使用者訊息並產生角色回覆
- **THEN** 不進行訊號偵測，角色回覆的送出時機不受影響

#### Scenario: Session 結束後偵測

- **WHEN** 一個 session 被判定結束
- **THEN** 系統以背景任務對該 session 的完整對話進行一次訊號偵測

#### Scenario: 偵測失敗

- **WHEN** 訊號偵測因模型錯誤或逾時而失敗
- **THEN** 系統記錄該失敗，並使該 session 可事後重新偵測，使用者不受影響

### Requirement: 訊號涵蓋教練評分維度

系統 SHALL 使記錄的訊號足以支撐後續教練回饋所需的評分維度，涵蓋提問品質、接話與延展、情緒感知、自我揭露平衡、分寸與界線與節奏。其中節奏的訊息長度與發送頻率由教練回饋階段自訊息紀錄統計，不要求即時訊號涵蓋。評分維度 MUST 固定為上述六項，角色的教練設定不得新增或變更維度。使用者所套用之角色版本的教練設定 MUST 能停用系統預設規則，並新增歸屬於上述維度的自訂規則（地雷、句點或亮點）；未經設定的項目 MUST 沿用系統預設，使未設定教練內容的角色維持既有行為。

#### Scenario: Session 結束後的訊號完整性

- **WHEN** 一個包含多次往返的 session 結束
- **THEN** 該 session 累積的訊號足以回答使用者在各評分維度上的表現，不需重新讀取原始對話進行分析

#### Scenario: 訊號可回溯至原句

- **WHEN** 需要根據某筆訊號說明使用者當時的表現
- **THEN** 該訊號可回溯至產生它的具體訊息內容，使回饋能引用使用者的原句

#### Scenario: 角色自訂規則

- **WHEN** 某角色的教練設定新增了自訂規則，且使用者的訊息命中該規則
- **THEN** 系統依該規則的類型記錄訊號，並標記為該規則所歸屬的維度

#### Scenario: 角色停用預設規則

- **WHEN** 某角色的教練設定停用了某條系統預設規則，且使用者的訊息符合該規則描述的行為
- **THEN** 系統不記錄該規則的訊號

#### Scenario: 角色未設定教練內容

- **WHEN** 某角色未停用任何預設規則，也未新增自訂規則
- **THEN** 系統以預設的判定準則偵測訊號，行為與設定功能導入前一致
